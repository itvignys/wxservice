# GPU智修专家 - 微信小程序

## 项目简介

GPU智修专家小程序是杭州秀源智能科技开发的英伟达显卡故障诊断与维修服务平台，为企业提供AI智能诊断、专家咨询、上门检测等阶梯式服务。

## 功能模块

### 1. 检测问答机器人 🤖
- **AI智能诊断**：基于知识库匹配和元宝AI的智能故障分析
- **图片识别**：支持上传故障图片进行初步诊断
- **服务阶梯**：
  - L1: AI智能问答（免费）
  - L2: 专家电话咨询（免费）
  - L3: 上门检测服务（企业首次免费）

### 2. 线上知识库 📚
- 基于Excel数据的问题库
- 分类筛选：显示类、驱动类、供电与过热、物理与接口、显存与核心、BIOS与固件
- 全文搜索：支持关键词检索
- 详细信息：问题原因、排查方法、维修方案、难度评估

### 3. 检测工具下载 🛠️
- GPU-Z：显卡参数检测
- FurMark：压力测试工具
- MATS：显存检测工具
- OCCT：系统稳定性测试
- 使用教程：完整的检测步骤指南

## 核心数据

知识库数据来源：`英伟达显卡维修问题汇总.xlsx`
- 共17条维修问题记录
- 6个分类：显示类、驱动类、供电与过热、物理与接口、显存与核心、BIOS与固件
- 包含问题描述、常见原因、排查方法、维修方案、难度、成本、成功率

## 技术栈

- 微信小程序原生开发
- CSS变量主题系统
- 本地存储管理
- 模拟AI接口（可替换为真实元宝API）

## 部署说明

1. 使用微信开发者工具打开项目
2. 修改 `project.config.json` 中的 `appid` 为你自己的小程序ID
3. 在开发者工具中上传代码
4. 在微信公众平台提交审核

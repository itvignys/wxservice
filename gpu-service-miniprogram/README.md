# GPU智修专家 - 微信小程序

一款专业的GPU显卡维修服务小程序，提供AI智能检测、专家一对一咨询、上门维修等一站式服务。

## 功能模块

### 1. AI智能检测问答机器人 🤖
- 智能问答快速诊断GPU故障
- 多轮对话深入分析问题
- 故障症状库匹配
- 维修建议自动生成
- 历史对话记录保存

### 2. 阶梯型服务体系 📈
- **AI检测（免费）**：智能问答故障诊断，24小时在线服务
- **专家一对一（¥99）**：资深工程师电话问诊，含1次免费上门检测
- **上门服务（¥299起）**：工程师上门检测，现场维修或取件

**企业用户专享**：填写真实企业信息即可享受一次免费上门检测服务

### 3. 线上知识库 📚
- 显卡故障分类浏览（花屏、黑屏、死机、性能下降等）
- 搜索功能快速定位问题
- 收藏功能保存重要内容
- 基于Excel数据源的问题库

### 4. 检测工具下载 🛠️
- MATS显存检测工具（显存坏块检测）
- CUDA MemTest（显存压力测试）
- GPU-Z（显卡信息查看）
- FurMark（显卡烤机测试）
- NVFlash（BIOS刷写工具）

每个工具都配有详细的使用教程

### 5. 个人中心 👤
- 用户信息管理
- 企业认证（享受企业用户权益）
- 预约记录查看
- 咨询历史
- 收藏内容管理
- 意见反馈

## 项目结构

```
gpu-service-miniprogram/
├── app.js                  # 小程序入口
├── app.json                # 全局配置
├── app.wxss                # 全局样式
├── sitemap.json            # 站点地图
├── data/                   # 数据文件
│   └── knowledge.js        # 知识库数据
└── pages/                  # 页面目录
    ├── index/              # 首页
    ├── chat/               # AI检测聊天
    ├── knowledge/          # 知识库
    │   └── detail/         # 知识详情
    ├── tools/              # 工具下载
    │   └── guide/          # 工具使用指南
    ├── expert/             # 专家服务
    │   └── book/           # 预约页面
    └── profile/            # 个人中心
        ├── company/        # 企业认证
        ├── bookings/       # 预约记录
        ├── history/        # 咨询历史
        ├── favorites/      # 收藏内容
        ├── about/          # 关于我们
        └── feedback/       # 意见反馈
```

## 技术特点

- **深色主题设计**：专业的科技感界面
- **响应式布局**：适配各种屏幕尺寸
- **本地数据存储**：使用wx.storage管理用户数据
- **模块化架构**：页面组件化，易于维护扩展

## 使用说明

1. 使用微信开发者工具打开项目
2. 在 `data/knowledge.js` 中导入知识库数据
3. 修改 `app.json` 中的页面路径配置
4. 编译预览并测试
